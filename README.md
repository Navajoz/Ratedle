# Ratedle 🎮
  browser game inspired by Gamedle, where you try to guess the rating of steam's top games
  
  ![image](https://github.com/user-attachments/assets/8e1319fe-3766-41ff-9f55-f71d04a35fe4)


## Features ✨
 - 100 random games
 - global ranking
